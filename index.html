Dica Android (Sobreposição Nativa & Bateria)

No Android, para manter a mira ativa sem ser fechada pelo sistema:

  • Vá em Configurações > Aplicativos.
  • Acesse Acesso Especial > Sobrepor a outros apps e habilite este app/navegador.
  • Desative a Otimização de Bateria para manter a execução contínua.

1. Como publicar no GitHub Pages

  1. Crie um repositório no GitHub (ex: my-crosshair-app).
  2. Crie um arquivo index.html e cole este código completo.
  3. Acesse Settings > Pages no repositório.
  4. Selecione a branch main e salve. O link do seu site estará pronto!

2. Transformar em App APK (Android)

Para transformar seu link do GitHub em um aplicativo APK instalado no celular com permissão total de overlay:

  • Opção 1 (Grátis & Rápida): Acesse o site WebIntoApp.com, insira a URL do seu GitHub Pages e clique em "Generate APK".
  • Opção 2 (PWA Oficial): Utilize o PWABuilder.com para criar um pacote Android Studio nativo com suporte a WebAPK.
